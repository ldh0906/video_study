# Lecture Lens

긴 강의도, 어려운 강의도 내 것이 될 때까지.

강의 영상 파일이나 강의 사이트 링크를 넣으면 받아쓰기 → 화면(슬라이드·판서) 분석 → 파트별 심층 노트 → 전체 구조 정리까지 자동으로 처리하고, 공부에 필요한 자료를 만들어 주는 로컬 앱입니다. AI는 **내 계정으로 로그인된 Claude Code CLI / Codex CLI**를 그대로 사용하므로 API 키가 필요 없습니다. (원하면 API 키 방식으로도 전환 가능)

## 주요 기능

| | |
|---|---|
| **가져오기** | 파일 드래그&드롭 · 로컬 경로(복사 없이 원본 사용) · URL(YouTube 등 yt-dlp 지원 사이트, 로그인 사이트는 브라우저 쿠키) · 자막 파일(.srt/.vtt) 첨부 |
| **받아쓰기** | 로컬 Whisper(whisper.cpp, 무료·오프라인) · 제작자/자동 자막 활용 · OpenAI 받아쓰기 API(선택) — 무음 구간에서 잘라 몇 시간짜리도 처리, 중단돼도 이어서 진행 |
| **화면 분석** | 슬라이드·판서가 바뀌는 장면(키프레임)을 캡처해 AI가 수식·도표까지 노트에 반영 |
| **개요** | 요약, 학습 목표, 강의 흐름(챕터), 막히기 쉬운 지점 해설, 선수 지식, 용어집 |
| **노트** | 챕터별 상세 노트(LaTeX 수식·표·코드), 모든 타임스탬프 클릭 시 해당 장면으로 이동, Markdown/PDF 내보내기 |
| **튜터** | 강의 전체를 아는 AI와 대화(스트리밍), “지금 보는 장면” 기준 질문, 대본/노트에서 텍스트 선택 → 질문·쉽게 설명·카드·메모 |
| **플래시카드** | 자동 생성 + SM-2 간격 반복 복습, 직접 추가·편집, AI로 더 만들기, Anki 내보내기 |
| **퀴즈** | 객관식(즉시 채점·해설) + 서술형(AI 채점), 틀린 문제만 다시 풀기, 난이도/범위 지정 새 퀴즈 |
| **마인드맵** | 강의 개념 구조를 인터랙티브 마인드맵으로 (SVG 저장) |
| **자료실** | 한 장 요약 노트 · 심화 해설 · 연습 문제(풀이 포함) · 예상 시험 문제 · FAQ · 원하는 자료 직접 요청 |
| **메모** | 강의 보며 쓰는 내 노트(Ctrl+T로 현재 시각 삽입) |
| **AI 설정** | 분석 모델 / 대화 모델 각각 Claude 또는 GPT, 모델·추론 강도(effort) 선택. Codex 계정에서 쓸 수 있는 모델 목록과 모델별 effort 단계를 자동으로 읽어옵니다 |

## 실행

필요한 것: **Node.js 20+**, 그리고 로그인된 **Claude Code CLI**(`claude`) 또는 **Codex CLI**(`codex`) 중 하나 이상.

```bash
npm install
npm run build
npm start
```

브라우저에서 <http://localhost:5178> 을 엽니다. Windows에서는 `start.bat`을 더블클릭해도 됩니다.

개발 모드(핫 리로드): `npm run dev` → <http://localhost:5177>

### 처음 한 번

1. **설정 → 받아쓰기**에서 *로컬 Whisper* 엔진 **설치**, 모델(**Large v3 Turbo** 추천) **받기**
2. **설정 → 도구**에서 yt-dlp **설치/업데이트** (URL 강의를 쓸 때. YouTube가 403을 내면 업데이트하세요)
3. **설정 → AI 모델**에서 분석/대화 모델과 추론 강도 선택 (기본: Claude Opus 5.5 · 높음 / Claude Sonnet 5.5 · 낮음)

## 긴·어려운 강의를 위한 처리 방식

1. **분할 받아쓰기** — 오디오를 약 10분 단위로, 문장이 끊기지 않게 무음 구간에서 자릅니다. 조각별 결과를 저장해 중간에 멈춰도 이어서 진행합니다.
2. **키프레임** — 키프레임만 디코딩해 장면 변화를 빠르게 찾고(최소 2분마다 1장), 파트마다 대표 장면을 AI에게 함께 보냅니다.
3. **파트별 심층 분석(map)** — 5~10분 파트마다 노트·핵심·개념·어려운 부분·카드를 구조화된 JSON으로 생성합니다. 음성 인식 오류는 문맥과 슬라이드로 바로잡고, 강의에 없는 보충 설명은 💡로 구분합니다.
4. **전체 정리(reduce)** — 파트 결과를 모아 실제 주제 전환에 맞춘 챕터, 요약, 용어집, 마인드맵을 만듭니다.
5. **튜터** — 강의가 충분히 짧으면 전체 대본을 통째로, 아주 길면 BM25로 관련 구간을 찾아 함께 보냅니다.

## 설계 참고

- **NotebookLM** — 자료(영상) / 대화 / 스튜디오(학습 자료) 구성과 출처 인용(타임스탬프) 방식
- **Readwise Reader · Notion** — 읽기 좋은 본문 타이포그래피, 차분한 종이 톤 팔레트
- **Anki** — 간격 반복 복습 흐름과 4단계 평가
- **Linear · Raycast** — 단축키 중심, 절제된 모션과 밀도
- 오픈소스: whisper.cpp, yt-dlp, ffmpeg, markmap, KaTeX

## 단축키

| 키 | 동작 |
|---|---|
| `Space` / `K` | 재생·일시정지 (카드 탭에선 카드 뒤집기) |
| `J` / `L`, `←` / `→` | 10초 / 5초 이동 |
| `F`, `M`, `<` `>` | 전체화면, 음소거, 재생 속도 |
| `1`–`4` | 카드 평가 · 객관식 답 선택 |
| `Ctrl+T` | 메모에 현재 시각 삽입 |

## 데이터와 설정

- 모든 데이터는 `data/`에 저장됩니다(강의별 영상·대본·분석·카드·퀴즈·대화, `settings.json`). git에는 올라가지 않습니다.
- CLI 모드에서는 API 키 환경변수를 자식 프로세스에서 제거해 **항상 로그인된 계정**을 사용합니다.
- 환경변수(선택): `LECTURE_API_PORT`(기본 5178), `LECTURE_DATA_DIR`, `CLAUDE_CLI_PATH`, `CODEX_CLI_PATH`, `WHISPER_CLI_PATH`, `YTDLP_PATH`, `FFMPEG_PATH`
