# Lecture Lens

긴 강의도, 어려운 강의도 내 것이 될 때까지.

처음 사용한다면 **[사용설명서](USER_GUIDE.md)**에서 실행, CLI 연결, 여러 영상 등록, GPU 받아쓰기와 오류 해결 방법을 확인하세요.

강의 영상 파일이나 강의 사이트 링크를 넣으면 받아쓰기 → 화면(슬라이드·판서) 분석 → 파트별 심층 노트 → 전체 구조 정리까지 자동으로 처리하고, 공부에 필요한 자료를 만들어 주는 로컬 앱입니다. AI는 **내 계정으로 로그인된 Claude Code CLI / Codex CLI**를 그대로 사용하므로 API 키가 필요 없습니다. (원하면 API 키 방식으로도 전환 가능)

|---|---|

| **받아쓰기** | 로컬 Whisper(whisper.cpp, 무료·오프라인) · 제작자/자동 자막 활용 · OpenAI 받아쓰기 API(선택) — 무음 구간에서 잘라 몇 시간짜리도 처리, 중단돼도 이어서 진행 |

| **튜터** | 강의 전체를 아는 AI와 대화(스트리밍), “지금 보는 장면” 기준 질문, 대본/노트에서 텍스트 선택 → 질문·쉽게 설명·카드·메모 |

## 여러 영상 한 번에 가져오기

- **파일** 탭에서 여러 영상·음성 파일을 선택하거나 함께 끌어다 놓습니다. 파일을 더 선택하면 목록에 추가되며, 같은 이름·크기·수정 시각의 파일은 중복 추가하지 않습니다. 각 영상은 별도 강의로 등록합니다.
- 업로드와 강의 등록은 한 파일씩 진행하며 파일별 진행률과 오류를 표시합니다. 등록된 강의는 기존 분석 대기열에서 하나씩 분석합니다. 등록 중에는 이 화면을 열어 두세요. **남은 업로드 멈추기**는 현재 파일 등록을 마친 뒤 다음 파일부터 멈추며, 이미 등록한 강의의 분석은 계속됩니다.
- 일부 파일에 오류가 있어도 나머지는 계속 등록합니다. 다시 시도하면 등록 완료 항목은 건너뜁니다. 강의 등록 단계에서 실패한 파일은 재시도할 때 다시 업로드합니다. 목록을 비우거나 항목을 제거해도 이미 등록된 강의는 삭제되지 않습니다.
- 자막을 함께 드롭하면 확장자를 제외한 파일 이름이 같은 영상에 연결합니다(예: `1강.mp4` + `1강.srt`). 영상 한 개와 자막 한 개만 있으면 이름이 달라도 연결합니다. 이름이 중복되거나 맞는 영상을 찾지 못한 자막은 알림을 표시하므로 영상 옆 **자막 첨부**로 직접 지정하세요.
- 여러 파일의 제목은 파일 이름으로 각각 정하고, 강의 메모·분석 모델·언어·화면 분석 설정은 공통으로 적용합니다. URL과 로컬 경로는 기존처럼 한 번에 하나씩 가져옵니다.

## 학습서 PDF

학습과학 연구(인출 연습·간격 반복·코넬 노트·이중 부호화)와 국내외 공부 커뮤니티(단권화·백지복습·오답노트·회독)를 참고해 설계했습니다.

- **프리셋** — 완전 학습서 / 빈칸 노트 / 시험 직전 요약판 / 문제집
- **레이아웃** — 필기 여백형(오른쪽 점 격자 메모 칸) · 코넬형(단서 질문·노트·요약) · 절약형, A4/B5
- **인출 중심** — 섹션마다 이해 확인 질문과 ‘덮고 3문장 요약’ 칸, 챕터마다 백지 복습 쪽, 섹션이 섞인 종합 문제(확신도·채점 칸)와 오답 노트, 접어 쓰는 플래시카드 시트
- **정답 분리** — 모든 정답·해설은 부록에 두고 `→ 정답 p.N` / `← 문제 p.N` 으로 양방향 연결
- **회독** — 회독 기록표(섹션 × 5회독), 섹션별 □□□□□, 복습 일정 D+1/3/7/14/30
- **탐색** — 쪽 번호가 들어간 목차, PDF 책갈피, 모든 내용에 ▶ 영상 시각 링크(YouTube는 해당 장면, 로컬 영상은 앱에서 그 시각으로 열림), 선택 시 챕터 QR
- **손필기판 / 타이핑판** — 타이핑판은 요약·답·여백 칸에 한글을 입력할 수 있고(Edge·Acrobat·PDF Expert), 다 쓴 PDF를 **메모 → PDF 메모 가져오기**로 앱 메모에 되돌릴 수 있습니다. 굿노트·노타빌리티는 손필기판을 쓰세요.

PC에 설치된 Microsoft Edge(또는 Chrome)로 조판하므로 추가 다운로드가 없습니다. 7분 강의 기준 26쪽을 약 5초에 만듭니다.

## 실행

필요한 것: **Node.js 20+**, 그리고 로그인된 **Claude Code CLI**(`claude`) 또는 **Codex CLI**(`codex`) 중 하나 이상.

```bash
npm install
npm run build
npm start
```

브라우저에서 <http://localhost:5178> 을 엽니다. Windows에서는 `start.bat`을 더블클릭해도 됩니다.

개발 모드(핫 리로드): `npm run dev` → <http://localhost:5177>

### 처음 한 번

1. **설정 → 받아쓰기**에서 *로컬 Whisper* 엔진 **설치**, 모델(**Large v3 Turbo** 추천) **받기**
2. **설정 → 도구**에서 yt-dlp **설치/업데이트** (URL 강의를 쓸 때. YouTube가 403을 내면 업데이트하세요)
3. **설정 → AI 모델**에서 분석/대화 모델과 추론 강도 선택 (기본: Claude Opus 5.5 · 높음 / Claude Sonnet 5.5 · 낮음)

## 긴·어려운 강의를 위한 처리 방식

1. **분할 받아쓰기** — 오디오를 약 10분 단위로, 문장이 끊기지 않게 무음 구간에서 자릅니다. 조각별 결과를 저장해 중간에 멈춰도 이어서 진행합니다.
2. **키프레임** — 키프레임만 디코딩해 장면 변화를 빠르게 찾고(최소 2분마다 1장), 파트마다 대표 장면을 AI에게 함께 보냅니다.
3. **파트별 심층 분석(map)** — 5~10분 파트마다 노트·핵심·개념·어려운 부분·카드를 구조화된 JSON으로 생성합니다. 음성 인식 오류는 문맥과 슬라이드로 바로잡고, 강의에 없는 보충 설명은 💡로 구분합니다.
4. **전체 정리(reduce)** — 파트 결과를 모아 실제 주제 전환에 맞춘 챕터, 요약, 용어집, 마인드맵을 만듭니다.
5. **튜터** — 강의가 충분히 짧으면 전체 대본을 통째로, 아주 길면 BM25로 관련 구간을 찾아 함께 보냅니다.

## 데이터와 설정

GPU용 whisper.cpp를 연결한 경우 설정의 받아쓰기 엔진에 GPU 이름이 표시됩니다. GPU 실행 파일과 런타임 DLL은 `data/bin/whisper-vulkan/`에 두고, 같은 폴더의 `accelerator.json`에 검증한 장치 번호(`device`)와 표시 이름(`label`)을 저장합니다. 앱은 이 엔진을 우선 사용하고 GPU 메모리 사용을 제한하기 위해 받아쓰기 조각을 하나씩 처리합니다. 이 노트북은 Vulkan 장치 1번의 Intel Arc A350M으로 검증했습니다. CPU 엔진은 기존 `data/bin/whisper/` 경로를 사용합니다.

- 모든 데이터는 `data/`에 저장됩니다(강의별 영상·대본·분석·카드·퀴즈·대화, `settings.json`). git에는 올라가지 않습니다.
- CLI 모드에서는 API 키 환경변수를 자식 프로세스에서 제거해 **항상 로그인된 계정**을 사용합니다.
- 환경변수(선택): `LECTURE_API_PORT`(기본 5178), `LECTURE_DATA_DIR`, `CLAUDE_CLI_PATH`, `CODEX_CLI_PATH`, `WHISPER_CLI_PATH`, `YTDLP_PATH`, `FFMPEG_PATH`
